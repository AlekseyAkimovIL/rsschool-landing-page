# Coffee House
 
Учебный проект RS School: адаптивный двухстраничный сайт кофейни (Landing Page, часть 1).
 
**[Открыть сайт](https://alekseyakimovil.github.io/rsschool-landing-page/)**
 
## Что внутри
 
- Главная страница: hero, слайдер, о нас, приложение.
- Страница каталога: категории и карточки напитков.
- Светлая и тёмная темы, выбор сохраняется в `localStorage`.
- Адаптивная вёрстка от 1440px до 380px, бургер-меню на планшете и мобильных.
## Технологии
 
HTML, SCSS (собирается в `css/style.css`), JavaScript без библиотек.
 
## Структура
 
```
index.html          главная страница
menu-coffee.html    каталог
css/                стили (style.css собирается из scss/)
scss/               исходники стилей
js/main.js          переключатель темы и бургер-меню
img/                изображения и иконки
fonts/              шрифт Inter
```
